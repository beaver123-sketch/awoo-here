# 猫在呢 · Awoo Here 🐈

手机优先的猫咪成长记录与像素小窝，MVP **v0.3**。

**在线体验**：本仓库根目录 `index.html` 是独立、完整的 HTML 应用，可直接在手机或桌面浏览器打开；部署到 Vercel 时无需构建。

## 当前功能

- 🐾 自主活动的像素小猫：走动、休息、伸懒腰、睡觉；去掉了点击摸头等模拟互动。
- 📸 「嗷呜一下」发布图文动态、标签；在「喵喵圈」浏览和点赞。
- 🩺 体重、疫苗、驱虫、就诊等健康记录与多猫档案。
- 💬 「懂喵君」本地记录问答（**并非在线大模型**）。
- 💚 猫猫屋、猫耳气泡、健康本本及花形发布按钮组成的新版底部导航。

## 隐私声明与当前限制

此仓库为**公开演示版**，只包含原创像素角色、场景和像素演示动态，**不包含真实猫咪原始照片**。用户后续在网站上主动上传的照片和健康数据，仅保存在当前浏览器的本地存储中；清除浏览器数据后可能丢失，建议使用应用的 JSON 备份功能。

尚未实现真实 AI 对话、账号、云端数据库、跨设备同步或 iOS 原生安装包。不建议在没有后端和安全保障前录入敏感医疗信息。

## 部署

直接在 Vercel 导入本仓库（Framework Preset 选择 **Other**，Root Directory 设为 `./`，无构建命令）。`index.html` 可作为静态网站首页。
