# 猫在呢 · Awoo Here

手机端猫咪日常记录与像素小窝，现已部署 **v0.6 — 真实照片头像**。

在线网站：https://awoo-here-z49l.vercel.app

## 本次更新：头像上传

- 点击首页、健康档案及猫咪资料中的头像即可打开系统相册。
- 上传本人猫咪真实照片后，可拖动调整位置并使用缩放滑杆完成圆形裁剪（保存为 512 × 512 JPEG）。
- 所有界面显示相同猫咪的真实头像；支持多个猫咪档案各自独立保存。
- 没有真实照片时只显示相机上传入口，不再默认使用卡通、抽象猫脸或像素图代替头像。
- 已有用户照片保留；旧内置占位头像自动迁移为空白上传状态。
- 电子小窝的像素猫角色及自动走动、伸懒腰等功能继续保留。

## 其他 MVP 功能

「嗷呜一下」图文发布与喵喵圈、健康小本本（体重、疫苗、驱虫、就诊、提醒）、多猫切换、JSON 本地备份。懂喵君目前为规则型本地记录助手，尚未接入真实 AI 模型。

## 项目结构

- 根目录 `index.html`：**正式线上入口，自包含 HTML / CSS / JavaScript / SVG / 像素猫素材。**
- `src/app.js` 与 `src/styles.css`：同步到 v0.6 的可编辑应用源码快照。后续编辑这些文件后，应重新合并至根目录的 `index.html` 才能影响线上版本。

## 隐私与数据说明

**仓库不包含你家猫咪的真实照片**。用户在网站上传的照片（含头像）、日常记录和健康档案当前仅存储在浏览器 LocalStorage 中，不会自动同步到 GitHub、Vercel 或云数据库。清除浏览器数据后可能丢失，应通过「设置与备份」导出 JSON 保存。当前没有账号登录、云端同步和原生安装包。
